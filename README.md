# Minecraft Mod Media

Public showcase assets for IronFaith Minecraft mods.

Each project has its own folder under `mods/` so CurseForge descriptions and
other public pages can link directly to stable images without exposing private
source repositories.

## Projects

- [WolfPhone](mods/wolfphone/images/)

## Folder convention

```text
mods/
  <mod-name>/
    images/
```
